# MASHAR Hackathon 2026

חלון ראווה לתוצרי האקתון 2026: פרויקטים, הדגמות וקישורים לתוצרים.

## אתר חי

**https://masharteam.github.io/MASHAR-Hackathon-2026/**

## מה יש כאן

- `index.html` — דף הבית של חלון הראווה
- `public/` — תמונות, צילומי מסך וקבצי פרויקטים
- `Avi_G/` — פרויקט Waves, Music and Technology
- `Oded/` — פרויקט מסלול למידה אישי מבוסס AI

## הרצה מקומית

פתחו את `index.html` בדפדפן, או הריצו שרת סטטי מקומי:

```bash
python -m http.server 8080
```

ואז גלשו ל־http://localhost:8080
